# Сховище акаунтів ДКВС

`accounts.json` — початковий файл облікових записів для майбутнього серверного сховища.

Запис акаунта має зберігати пароль лише у вигляді стійкого salted-хешу, наприклад `passwordHash` і `passwordSalt`. Не додавати сюди відкриті паролі.

Поточний демосайт ще не підключений до цієї папки: він зберігає користувачів у `localStorage` браузера. Для спільного збереження між працівниками потрібен серверний API; файлова структура сама по собі не змінює поведінку сайту.
